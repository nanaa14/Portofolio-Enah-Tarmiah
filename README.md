# Portofolio Enah Tarmiah

Website portofolio statis berbasis HTML, CSS, dan JavaScript.

## Menjalankan secara lokal
Buka `index.html` di browser. Untuk pengalaman terbaik, jalankan melalui Live Server di VS Code.

## Deploy ke GitHub Pages
1. Buat repository GitHub baru.
2. Ekstrak seluruh isi ZIP ini, lalu upload semua file (folder `assets` dan `index.html`) ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.

## Deploy ke Vercel
1. Push isi folder ini ke repository GitHub.
2. Login ke Vercel dan pilih **Add New → Project**.
3. Import repository tersebut.
4. Framework Preset pilih **Other**, Build Command dan Output Directory bisa dikosongkan (atau output directory `.`).
5. Klik **Deploy**.

## Catatan
- Data kontak, pendidikan, dan pengalaman ditulis berdasarkan CV yang diberikan.
- Belum ada tautan LinkedIn/Instagram/portofolio proyek yang dicantumkan karena belum diberikan.
- Foto profil diambil dari foto pada CV yang diberikan.
